# Time Series Analysis on Stock Prices Dataset

## Objective
To analyze stock price trends and identify patterns using Time Series Analysis techniques.

## Tools Used
- Python
- Pandas
- Matplotlib
- Statsmodels
- VS Code

## Dataset
Stock Prices Dataset

### Columns
- Symbol
- Date
- Open
- High
- Low
- Close
- Volume

## Analysis Performed
1. Trend Analysis
2. Moving Average Smoothing
3. Seasonal Decomposition

## Output Files
- Trend.png
- MovingAverage.png
- Decomposition.png

## Conclusion
This project analyzes stock price data using Time Series Analysis techniques. Trend analysis, moving average smoothing, and seasonal decomposition were performed to identify patterns and understand stock price behavior over time.
